# Personal projects

This is where I keep my data science projects. Each one starts with a business question, follows the data, and ends with a decision a team could use.

## Folders

**[security-friction-ab-test](security-friction-ab-test/)** is a simulated A/B test of account recovery. Treatment adds phone verification. The question is whether that extra check is worth the friction it adds for genuine users.

**[product-quality](product-quality/)** uses real Olist orders. The question is which product categories are more prone to a bad review, and whether that is still true when the order arrived on time.

Each folder has its own README with how to run the project and what the analysis concluded.
